## Cover lookup

Open Library matches are stored separately in `src/data/book-covers.json`. They identify the work, not necessarily the photographed Greek edition. Entries marked for review are skipped. Missing or failed covers use a title thumbnail. Run `python3 scripts/lookup-book-covers.py` to look up uncached matches; existing matches are retained.
